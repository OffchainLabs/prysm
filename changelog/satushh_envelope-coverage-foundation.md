### Added

- Add a dedicated `dbval.EnvelopeCoverage` record tracking the proven execution payload envelope coverage interval `[low_slot, high_slot)` with its canonical upper anchor, plus a coordinator-owned `revealed-envelope-slot-index` bucket mapping each revealed canonical slot to the single envelope root the canonical chain actually used. Both are committed together through a combined Bolt accessor that range-replaces index intervals exactly and rechecks every put against the validated primary envelope fingerprint; `DeleteExecutionPayloadEnvelope` now refuses to delete an indexed root with a typed `ErrEnvelopeCovered`.
- Add a standalone node-owned `beacon-chain/coverage` runtime whose coordinator is the sole writer of envelope coverage: it bootstraps or migrates coverage from an empty head-anchored interval using candidate/byte-budgeted cursor pages over the block slot index (with an ephemeral `(slot, offset, lastRoot)` resume token), publishes progressively, extends toward the canonical head and the retention floor, shrinks or discards the interval on reorgs (deleting the common-ancestor index key whose fullness testimony can flip), and bumps an in-process serve epoch on destructive commits. `SaveOrigin` seeds an empty coverage interval for Gloas+ checkpoints.
- Add an `Env` retention span to `das.SyncNeeds` (`max(1, gloasStart, epoch-floored MIN_EPOCHS_FOR_BLOCK_REQUESTS offset)`, excluding the envelope-less genesis slot); the default block retention lower bound is now epoch floored and a `--backfill-oldest-slot` flag combines with `min()` so the oldest envelope epoch is never stranded.
- Rewrite the `ExecutionPayloadEnvelopesByRange` RPC handler as a coverage-gated serving path: it evaluates the requester's original range intersected with the envelope domain `[max(1, gloasStart), current]` without rewriting bounds, collects first from proven coverage through the canonical-revealed slot index (O(quota) per request, never O(window)), validates every item against its canonical block and bid with payload-hash continuity, serves a validated present-head envelope at the live frontier (a stored head envelope is now included instead of being silently omitted), refuses real gaps with `ResourceUnavailable` before the first chunk, and retries once on a destructive serve-epoch change. New metrics cover coverage bounds, migration progress, live-frontier response shapes, empty-domain requests, quota truncation, serve-epoch invalidations, and covered-delete refusals.
- Note for operators: this introduces an irreversible database addition. An in-place downgrade to a pre-coverage binary is unsupported (it would serve envelope ranges without the coverage gate); roll back by deleting and resyncing the beacon database. After upgrading an existing database, historical envelope ranges refuse with `ResourceUnavailable` until the progressive startup migration publishes the corresponding coverage pages, and this foundation does not yet fetch missing historical envelopes.
